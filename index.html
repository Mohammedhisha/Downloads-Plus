Changelog

What's New in 1.1.0

The toolbar popup is here — and it brought friends.

  • Toolbar popup — Click the extension icon for a searchable popup with live speed and progress, without leaving the page.
  • Time remaining — Every active download now shows how long is left, next to the speed, in both surfaces.
  • Date headings — Downloads are grouped under Today, Yesterday, Last 7 days, and then the date.
  • Progress ring — The toolbar icon fills as downloads run, counts multiples, goes green on completion or red on failure.
  • Keyboard shortcuts — Show in folder, copy link, pause, resume, retry, cancel and remove. All rebindable.
  • Chrome UI hidden — Chrome's download button and bubble are hidden so they don't cover the popup. Reversible in Settings.
  • Themes — A light theme that no longer flashes, with a smooth animated selector.
  • Auto-clear — Clear completed downloads after 1h, 24h or 7d. Failed ones are always kept.
  • Search fix — No longer breaks on filenames with brackets or parentheses.
  • Accessibility — Sorting, dropdowns and settings rebuilt for keyboard and screen reader use.

Guide

How It Works

A step-by-step walkthrough of every surface and interaction.

The Popup

Click the Downloads Plus icon in your toolbar. A compact popup appears showing your most recent downloads. Active downloads are pinned to the top with live speed (MB/s) and estimated time remaining. Use the search bar to filter by name, URL or tag. Each row has inline action buttons: pause/resume, cancel, show in folder, copy link, and remove.

The Full Page

Press Ctrl+J or click "Show all downloads" in the popup footer. The full-page dashboard replaces Chrome's default downloads page. Search all files, sort by any column, expand any card for its source URL, file path and size. Downloads are grouped — Today, Yesterday, Last 7 days — then by specific date.

Active Downloads

When a download starts, its card lights up with a blue ambient glow. A progress bar fills across the card, and you see live transfer speed and how long is left. The toolbar icon shows a progress ring that fills as your download runs. Multiple downloads show a count badge.

Search & Tags

Type a filename, URL fragment, or tag like "pdf" or "1080p". Matches are highlighted as you type. Smart tags are extracted automatically: resolution (720p, 1080p, 4K), codecs (x265, HEVC, AV1), audio (DTS, Atmos, FLAC), and file extensions.

Settings

Click the gear icon. Choose your theme (dark, light, or system), set a default sort column, enable single-card expansion, hide or show Chrome's download button, set an auto-clear timer, and rebind every keyboard shortcut. Changes sync instantly across popup and full page.
